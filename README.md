# اوستای گویا

خوانش اوستا، بخش به بخش، با نگاره و آهنگ. این انبار سرچشمه‌ی داده‌های برنامه‌ی (اَپ) رایگان «اوستای گویا» است.

از کارهای **رسانه‌ی ایرانا**.

## ساختار

| جا | چیست |
|---|---|
| `fehrest.json` | فهرست همه‌ی بخش‌ها به ترتیب، با دسته‌ها و نشانی پرونده‌ها |
| `bakhsh-ha/<id>.json` | داده‌ی هر بخش: متن هر بند، زمان آغاز و پایان آن در آوا، نگاره، واژه‌نامه |
| `ava/<id>.m4a` | آوای خوانش هر بخش |
| Releases | نمای (ویدیوی) هر بخش، با نگاره و آهنگ |

## شناسنامه‌ی هر بخش (`bakhsh-ha/<id>.json`)

- `id`، `order`، `title`، `group` (مانند گاتاها)، `book` (یسنا، یشت‌ها، وندیداد، ویسپرد، خرده‌اوستا)، `hat`
- `categories`: دسته‌ها برای جست‌وجو و چینش در اَپ
- `audio`: `file`، `duration` (ثانیه)، `title_end` (پایان خواندن سرنام)
- `video`: `url` پیوند نما
- `verses[]`: `n` شماره‌ی بند، `start` و `end` (ثانیه در آوا)، `text`، `scene` (نگاره)
- `glossary[]`: `term` و `meaning`
